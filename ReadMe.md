# 📩 Spam-Ham Classification using NLP and Naive Bayes

## 📌 Project Overview

This project is a **Spam-Ham Message Classification System** that uses **Natural Language Processing (NLP)** and the **Multinomial Naive Bayes Classifier** to identify whether a given message is **Spam** or **Ham (Normal Message)**.

The system takes a text message as input, processes and cleans the text using NLP techniques, converts the text into numerical features using **Bag of Words (BoW)**, and then uses a trained **Naive Bayes model** to classify the message.

### Classification

* **Ham** → Normal and genuine message
* **Spam** → Unwanted, promotional, suspicious, or fraudulent message

---

## 🎯 Project Objective

The main objective of this project is to build a machine learning system that can automatically detect unwanted messages.

For example:

```text

Output:

```

```text
Input:

Output:
```

## 📚 NLP Techniques Used

### 1. Text Cleaning

Unwanted characters such as numbers and special characters are removed from the message.

Example:

```text
"Hello!!! How are you?"
```

After cleaning:

```text
"Hello How are you"
```

---

### 2. Lowercase Conversion

All text is converted into lowercase so that words such as:

```text
Hello
HELLO
hello
```

are treated similarly.

---

### 3. Tokenization

The sentence is divided into individual words.

Example:

```text
"Hello how are you"
```

becomes:

```text
["hello", "how", "are", "you"]
```

---

### 4. Stopword Removal

Common words that provide less useful information for classification are removed.

Examples:

```text
is
the
are
a
an
to
```

---

### 5. Lemmatization

Words are converted into their basic form.

Example:

```text
running → running
studies → study
cars → car
```

This helps reduce different forms of similar words.

---

## 🔢 Feature Extraction using Bag of Words

After preprocessing, the text needs to be converted into numbers because machine learning models cannot directly understand raw text.

This project uses:

```python
CountVectorizer(
    max_features=1000,
    ngram_range=(1, 2)
)
```

### Why Bag of Words?

Bag of Words represents text using the frequency of words or phrases appearing in the message.

For example:

```text
"win money now"
```

can be converted into a numerical vector based on the vocabulary learned from the training dataset.

### N-Grams

The project uses:

```python
ngram_range=(1, 2)
```

This allows the model to learn both:

* Unigrams → individual words
* Bigrams → two-word combinations

For example:

```text
"claim your reward"
```

can produce:

```text
claim
your
reward
claim your
your reward
```

This helps the model understand phrases instead of relying only on individual words.

## 🤖 Machine Learning Model

The project uses the:

### Multinomial Naive Bayes Classifier

```python
from sklearn.naive_bayes import MultinomialNB

model = MultinomialNB()
model.fit(x, y)
```

Multinomial Naive Bayes works well for text classification because it can work with word-count based features generated by Bag of Words.

The model learns patterns from:

```text
Ham Messages
+
Spam Messages
```

and uses these patterns to classify new messages.

## 🏷️ Label Encoding

The dataset contains two labels:

```text
Ham
Spam
```

These labels are converted into numerical values using `LabelEncoder`.

```python
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
y = le.fit_transform(ds["labels"])
```

The encoded values are then used to train the machine learning model.

After training, the trained components can be saved using Joblib.

For example:


## ⚠️ Limitations

The performance of the classifier depends heavily on the quality and size of the training dataset.

Some messages can be difficult to classify because Ham and Spam messages may contain similar words.

For example:

```text
"Can you lend me 50 rupees?"
```

is a normal **Ham** message.

While:

```text
"You have won 50,000 rupees. Claim now!"
```

is **Spam**.

Therefore, using a larger and more diverse dataset can improve the model's performance.

## 📈 Evaluation Metrics

The model can be evaluated using:

* **Accuracy** — Overall correct predictions
* **Precision** — How many predicted Spam messages were actually Spam
* **Recall** — How many actual Spam messages were detected
* **F1-Score** — Balance between Precision and Recall
* **Confusion Matrix** — Shows correct and incorrect classifications
